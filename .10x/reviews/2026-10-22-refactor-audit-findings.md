## Area summaries

- **game-spells**: src/ArcaneCore.Game/Spells is 310 .cs files (about 37.5k lines) in 45 folders. Its core is one `public sealed partial class SpellSystem` spread over 89 partial files (78 in the root, about 11.7k lines; SpellSystem.cs alone is 2259 lines, SpellSystem.Auras.cs 1198). It holds roughly 56 private fields and 60 settable seam properties. Around it sit feature folders: Auras, Procs, Mods, Rules (Immunity, Diminishing, CrowdControl), Casters, Stances, Effects, Checks, per-class script folders, and Generic/Holidays/WorldEvents dummy scripts. Extension is by `[SpellScript(ids)]` ISpellScript classes (129 in the area, found by assembly reflection scan in SpellScriptRegistry), ISpellHandlerModule registrations, and seam interfaces with injectable defaults. The code is dense with vmangos file:line citations and is generally clean. There are no TODOs, no async code, and every catch uses `when (ex is not OutOfMemoryException)`. The dominant file convention is the type name, or `SpellSystem.<Feature>.cs` for partials. Namespaces match folders only for Rules, Mods, Procs.Talents and the class folders. The 68 files in Auras, Effects, Stances, Procs, Checks and similar folders use the flat root namespace `ArcaneCore.Game.Spells`. Private statics are mostly `s_camelCase` (26 against about 14 PascalCase). The biggest repeated-logic problems are copy-pasted vmangos helpers (rand_dither, IsWithinDistInMap, Get/SetPower) and 18 identical fault-recording catch blocks.
- **game-creatures**: src/ArcaneCore.Game/Creatures (about 195 files, ~44k lines) and Npc (36 files, ~7k lines) hold the creature runtime and the NPC service layer. Creatures is one per-map update system, CreatureMapSystem, split into 43 partial files (10,362 lines), plus Creature, AI (CreatureAI, ScriptedAI, EscortAI, FollowerAI, EventAI, SmartAI), Movement generators, Guards, Respawn, and about 80 hand-ported ScriptDev-style scripts under Scripts. Npc is mostly QuestNpcServices, a facade split into 23 partial files (5,704 lines), plus NpcStore, NpcPackets, TaxiFlightSystem and the collaborator contracts in NpcServiceContracts.cs. Measured conventions. Private fields are _camelCase with braces nearly everywhere.
