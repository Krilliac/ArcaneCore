Same commits: the tests whose expectations the merges changed (sd2-mid's import test, the gossip-slot tests now look for their script among the wrapping layers via `GossipScriptLayers`, the `QuestAccepted` handler type).
* `ecf58cdd` `arcane-mock live` now answers `SMSG_NEW_WORLD` with `MSG_MOVE_WORLDPORT_ACK`. Without it a scripted GM `.tele` into a dungeon left the session between maps (found by the rehearsal's Deadmines check; tool-only change).
