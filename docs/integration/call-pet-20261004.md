# Hunter call-current pet (`SUMMON_PET`, effect 56)

This slice implements only player/hunter effect 56 with effect misc entry zero (call current).
It consumes the login-preloaded current snapshot synchronously on the world thread; it does not
perform database I/O inside spell effect execution and does not invent a template or subtype.
An existing live or retained corpse pet causes the source-compatible refusal. A missing cached
row sends `SMSG_PET_TAME_FAILURE` reason 7; a cached health-zero row sends reason 10. A positive
snapshot restores through the existing action-bar/spell/cooldown path and preserves the stable
pet number while allocating the transient world GUID normally.

Ground truth: vmangos `SpellEffects.cpp:3171-3223` and `Unit.cpp:5116-5143`; failure values are
`SharedDefines.h:1707-1721`, and the one-byte packet is opcode 371. Nonzero creature entries,
hunter tame/stable subtype, and warlock/demon replacement remain pending separate producers.
