This lane adds the Temple of Ahn'Qiraj instance script and the first two encounters: Prophet Skeram and the Bug Trio. It does not claim an AQ40 clear. Reference source was read for behavior and numeric facts; no GPL code or other third-party code was copied.

The Bug Trio wipe can restore a dead creature before its four-second corpse despawn fires. `CreatureMapSystem.ForceRespawn` now clears that pending despawn for the creature it restores; the wipe test advances the world clock past the old deadline.

The Bug Trio uses ScriptDev2's specific Kri cleave/cloud, Yauj fear/ravage, and Vem knock away IDs instead of vmangos' documented temporary substitutions. Yauj brood points use vmangos' 40-yard and room-center line-of-sight checks. The bounded retry skips a brood if no valid point exists; a live map with the vmap/terrain set is still needed to assess those points. The test creature data are synthetic; no content row was invented in production.

## Tests and evidence

`TempleOfAhnQirajTests` checks registration, pull state, all three Skeram image-health stages, distinct platform blink casts, timed Arcane Explosion/True Fulfillment, image cleanup after death and wipe, persistent state, and gate transitions. `BugTrioTests` checks linked pull, each member's signature cast, first-two death consumption, Vem vengeance, Kri cloud, ten Yauj brood, final completion, and wipe respawn from database spawns. The map 531 case is added to `RaidRegistrationTests`; the known-map registry list includes 531.

Intake review (2026-10-08) made two fidelity fixes and added a test for each: the true prophet's death no longer cancels True Fulfillment (vmangos `boss_skeramAI::JustDied` cancels it only for an image), and Vem's Knockdown waits for someone in melee range (vmangos `boss_vemAI::UpdateBugAI`). The Skeram blink test now asserts three distinct platform spells, not just three casts.

Native intake results (Release, after the fixes): solution build 0 warnings, 0 errors; `TempleOfAhnQirajTests` + `BugTrioTests` 12 passed, 0 failed; full Game project 7,581 passed, 15 skipped, 0 failed; full World project 3,230 passed, 31 skipped, 1 failed (`LiveFxCommandTests.AMissingFile_LeavesThatKindUnchecked_TheOthersStayChecked`, a known load flake that passed on rerun: 22 passed, 1 skipped). Each key test was shown to fail with its feature broken: Bug Trio distinct-death completion, the `ForceRespawn` pending-despawn clear, Vem's knockdown gate, the prophet-death fulfillment rule, distinct blink platforms and phase-dependent image health. No imported-world, multiplayer, or real-client AQ40 run was performed.

## 2026-10-09 Princess Huhuran follow-up

Huhuran (15509) now has a registered encounter AI. Its timers and 30-percent/five-minute Berserk follow vmangos `boss_huhuran.cpp`; the instance's Huhuran slot reaches InProgress, Fail and Done through a normal pull, wipe and kill. `HuhuranSpellModule` makes Wyvern Sting 26180 choose the closest ten targets and Poison Bolt Volley 26052 the closest fifteen, as the vmangos target-map scripts do. Wyvern Sting removal casts 26233 for 500 damage on expiry or 3000 on dispel, following the mangos-classic aura script. The scripted 80-yard sight check runs when the creature receives a line-of-sight notification; the default relocation notifier visits candidates only within its configured 40-yard radius, as in the reference's maximum-creature-attack-radius gate. Focused tests cover the AI with a fake caster, the area and aura rules with synthetic spells, and a Frenzy-to-Volley cast through the live `SpellSystem`. Imported-world combat and real-client behavior remain unverified. Sartura, Fankriss, Viscidus, Twin Emperors, Ouro and C'Thun still have no encounter AI.
