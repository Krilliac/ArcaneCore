### Found during the rehearsal

* **A dead (released-ghost) GM gets no response to any chat command.** In run A the operator character Claudeop died (teleported among
  level-39 Skullsplitters) and released. From then on every `.server shutdown 10` it sent was silently dropped, with no `Command:` log line,
  so `stop_new.py`, and therefore `deploy_w4.py`'s step 1, failed safely with "did not exit gracefully". This also reproduces on
  integrated-w9 (`profile-ghost`, `ghost-w9`), so it is not a wave-10 regression. If the live operator is ever a ghost, the deploy aborts
  without stopping anything. A follow-up task was filed. Workaround in the rehearsal: a living operator character (`REHEARSAL_OP_CHAR`).
* **arcane-mock stops sending under a continuous packet stream.** An operator logged in next to the moving STV patrol never got past its
  first command, because `DrainAsync` waits for a quiet period that never comes. claude/grind-stall (wave 11) carries this mock fix.
* A same-map `.go creature` is not followed by the mock (it does not ack a near teleport). The rehearsal teleports cross-map first
  (`.tele deadmines`).
