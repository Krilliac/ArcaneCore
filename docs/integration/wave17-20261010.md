* **Config (e7fdd74a).** claude/tick-scaling added `MapOptions.GridPrefetchDistance` without a `WorldConfigKeys` entry:
  `ConfigReloadTests.EveryWorldOption_IsClassified_LiveOrRestartOnly` and `ConfigReferenceTests.Production_ConfigurationReference_MatchesTheCommittedPage`
  failed. `GridContainer` reads it on every approach, so it is live like `GridActivationDistance`.
* **Bot plan cost (ac326b41), needs review.** claude/bot-stall-patterns (WIP 86f273f8) plans to the goal first, then falls back to the
  straight-line points, and steps beside a mesh fragment (`FromBeside`, up to 16 queries) on any refusal. With an unreachable goal one plan
  attempt cost 38 queries (`PlayerbotQuestTravelPriorityTests.UnreachableCandidateIsBlockedAndBacksOffAfterOnePlanAttempt` expected 3) and
  `PlayerbotWorldDestinationsTests.BlockedNearestHintRotatesToReachableSameEntryOnNextThink` expected 2, got 4. Changed in
  `PlayerbotNavigation`: the goal-first query is skipped when the first straight-line point is the goal itself; a refusal the mesh judged
  (not a refused straight line) ends the attempt instead of retrying shorter points; `FromBeside` runs only for a partial corridor, not a
  no-path answer from off the mesh. All 895 Playerbot/ConfigReload/Docs World tests pass. This changes the branch's behaviour, not only its
  tests: whoever owns bot-stall-patterns should confirm it before the next live stress run.
