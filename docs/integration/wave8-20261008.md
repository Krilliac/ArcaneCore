integrity algorithms (wow_srp_csharp, MIT), DotRecast (test oracle only, Zlib), WowWorldMessages vanilla test oracle (MIT).

How chat and groups share the party intake: invitations, chat, loot rolls and resurrection offers all come through `PlayerbotPartyAI.Intake`.
An invitation is answered by `OnInvite` before and independently of any chat line, and is accepted when the coordinator formed the group
(`AcceptsBotGroup`) or the invite policy allows it; chat only adds replies through `Converse`, which never answers an invitation. Bots'
own party/say lines are classified `Ignore`, so grouped bots do not chat with each other.
