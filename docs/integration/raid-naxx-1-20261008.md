# Naxxramas part 1: Arachnid and Plague quarters (2026-10-08)

Map 533 has a 15-slot ScriptDev2 save string. Slots 0–5 are the six bosses in this slice; slots 6–14 are reserved for the remaining encounters. The four end-boss states control the wing return portals and the central Frostwyrm gate. No schema version was taken. All behaviour was independently implemented from the GPL reference; no reference source was copied and no new third-party notice is needed.

## Content and tests

ClassicDB `ClassicDB_1_12_1_z2815.sql.gz` contains all 13 creature templates used by these mechanics and the checked wing portal/gate templates. Its four wing portals are goober objects with spell 28444; `spell_target_position` sends that spell to map 533 at `(3005.74, -3434.27, 304.196)`. Its `creature_ai_scripts` row `1628601` casts Fungal Bloom (29232) when a Spore dies. An already imported world needs those rows refreshed if absent. The scripted spell casts also need the 5875 client DBC spell data.

`NaxxramasTests.cs` uses synthetic map/content and a controlled update interval to check registration, saved state, gates, all four portal uses, one real spell-system teleport to the ClassicDB position, each boss's main phase, multi-stage Noth, staged Maexxna wrap, Heigan fissures, Loatheb Doom/spores, Faerlina's Widow's Embrace (and that a plain worshipper kill is not one), the worshipper's self-kill, Heigan's port rotation, the untouched later-wing gates, Anub's guards/scarabs and Corrupted Mind's Druid follow-up. Heigan's port and Maexxna's wrap also run through the real `SpellSystem` with the ClassicDB target layout of 29273 and 28622 (the player moves to the spell_target_position and Heigan stays put; the player, not Maexxna, gets the wrap aura, and the cocoon's death removes it); Anub's guards come from two database spawns; the World test `NaxxramasFrostwyrmGateTests` evaluates the 4156 row exactly as `TeleportHandlers` does. It does not constitute an imported-world or real-client clear.

## Fidelity limits to resolve in live acceptance

- Maexxna moves wrapped players with a same-map teleport to the vmangos wall coordinates; the reference uses a visible knockback flight. The client movement and cocoon-release path need a real-client party run.
- Heigan activates the imported trap groups and creates short-lived fissures at the vmangos unsafe points, but the floor traps do not play vmangos' custom animation. The eruption damage path needs imported-world verification.
- The five scarabs on player death are detected on the next map tick because the current instance hook has no player-death callback. The Crypt Guard corpse timer uses the reference 20–80-second window.
- Noth's summons require the matching 5875 spell data, and the late third-wave constructs require creature template 16982. Loatheb's spore Fungal Bloom requires the imported EventAI death row. These effects are not proven by a real-content combat run.
- Heigan's floor-trap grouping keeps vmangos' exception spawn GUIDs (533181-533200); ClassicDB z2815 numbers map 533 spawns 533xxxx, so only the entry ranges apply to imported content.
- Heigan's Mana Burn keeps the DBC 25-yd area radius; vmangos' `HeiganManaBurnScript` widens it to 28 yd. The cast is gated at 28 yd as in vmangos, so a mana user between 25 and 28 yd causes a cast that does not reach them. ArcaneCore has no per-spell radius override seam yet.
- Heigan's port does not send vmangos' 30211 spell-go visual at the old and new positions.
- A database without ClassicDB's two Crypt Guard spawns (vmangos' own world DB) gets no pre-pull guards, by design: the script follows mangos-classic and the stated content source.
- creature_linking FLAG_FOLLOW (the 1024 bit of the Crypt Guards' 1031) is not carried, as for Molten Core.
- Anub'Rekhan casts mangos-classic's aura 29103 on pull; ArcaneCore has no handler for its 29104/29105 corpse-scarab chain, so the five scarabs come only from the map-tick player-death check (no double spawn today; a future generic 29105 summon would need that check removed).
- The remaining Naxxramas boss scripts, wing encounters, dialogue and a complete raid clear are outside this part-1 worktree.

## Intake review (2026-10-08)

The Codex lane's diff was reviewed against vmangos and mangos-classic before commit. Changes made at intake:

- Faerlina: removed the "any worshipper death casts Widow's Embrace" trigger (a later-expansion mechanic, in neither 1.12 reference); added `WidowsEmbraceScript` for the 1.12 path.
- Instance: stopped driving Military/Construct/Frostwyrm gates and Heigan's unused exit door 181203 (would have shut ClassicDB's start-open Gothik gate with no script to reopen it).
- Noth: balcony flags are mangos-classic's `UNIT_FLAG_UNINTERACTIBLE | UNIT_FLAG_IMMUNE_TO_PLAYER` instead of an unreferenced NonAttackable2.
- Heigan: ports follow vmangos' one-shot 40 s / 18+48 s schedule with the per-rotation exclusion instead of a fixed 48-second repeat of the first three threat entries; fever, mana burn and eruption timers restart as in `EventDanceEnd`.
- Maexxna: web-wrap targets are random non-tank players (vmangos `DoCastWebWrap`), not the first three on the threat list.
- Removed duplicate zone-pull and fail-state calls already made by `RaidCreatureAI`.

## Rework (2026-10-08, second review)

- Heigan's port and Maexxna's wrap were cast by the boss. ClassicDB 29273 and 28622 target UNIT_CASTER, so Heigan teleported himself and Maexxna stunned herself; the wrapped player got nothing, the cocoon release never fired and the "already wrapped" filter never excluded anyone. Both are now cast by the player on itself through a new creature-spell seam, `ICreatureSpellCaster.CastByUnit` / `CreatureMapSystem.CastSpellByUnit` (default: no spell system).
- The Frostwyrm trigger's ClassicDB `areatrigger_teleport` row ran whatever the instance hook did. New generic seam: `InstanceData.BlocksAreaTriggerTeleport`, consulted by `InstanceFeature` as an `IAreaTriggerGate`; Naxxramas blocks 4156 until the four wings are done and no longer teleports itself.
- Anub'Rekhan no longer summons the two pre-pull guards that ClassicDB already spawns (four guards on imported content); evade respawns the database pair instead.
- Heigan: Mana Burn gated on a mana user within 28 yd with vmangos' 3 s / 1 s cadence; plague waves at the 20 eye stalks during the dance. Maexxna: the wrap cooldown restarts when nobody can be wrapped (it retried every tick).
- Each new test was run against the pre-rework code and failed there (11 Game tests, 1 World test), then passed after.
