## Recommended appsettings for the live stress test

Bot caps (`World:Playerbots`; the live profile, like the rehearsal copy, has `HotReload:Commands` false, so set them before the deploy
and let the deploy's restart read them, or turn `HotReload:Commands` on to use `.reload config` afterwards):

    "World": { "Playerbots": { "MaxBots": 410, "MaxRegisteredBots": 1000 } }

`MaxBots` counts running bots only: the stress script's last bot step (400) plus Nathan's 5 running bots, with a little headroom.
`MaxRegisteredBots` 1000 is the default (it can be left out). The validator ceiling is 1000; it is not a recommended running count.

Connections: no change needed. Both listeners bind 127.0.0.1, so `Net:Protection:ExemptLoopbackOnLoopbackBind` (default true) lifts the
shared per-address cap of 16 for local clients. The rate limits still apply per daemon: `Net:Protection:ConnectionBurstPerIp` 100 and
`ConnectionsPerMinutePerIp` 300 - the stress script's one client per 0.4 s is 150 per minute per daemon. Raise
`ConnectionsPerMinutePerIp` only if clients are spawned faster than about one per 0.2 s. `Auth:`/`World:MaxConnectionsPerIp` and
`MaxConnections` stay 0 (unlimited).
