# Script fidelity review: verdicts (2026-10-08)

Every finding of the LLM fidelity review (`D:/ArcaneCore-lanes/_plan/llm-fidelity-review-20261008.md`, outside the repo; 96 rows, model claims comparing the ported dungeon/raid scripts with mangos-classic ScriptDev2 and vmangos) checked against both reference sources by hand, on branch `claude/script-fidelity` from `ddebfd52`. Fixes are in commit `076a6861`; each has a test in `tests/ArcaneCore.Game.Tests/Instances/ScriptFidelityTests.cs` (plus one each in `RaidBossTests.cs` and `DungeonScriptExpansionTests.cs`) that fails on `ddebfd52` and passes on `076a6861`.

Verdicts: **fixed** (confirmed, fixed in `076a6861`), **partial, fixed** (the true part fixed), **open** (confirmed, not fixed - cosmetic, feature work or an engine gap; the note says which), **partial** (only part of the claim holds), **unconfirmed**, **false** (false positive, with the reason), **out of scope** (Codex lanes: Blackwing Lair 469, Zul'Gurub 309, Ruins of Ahn'Qiraj 509).

## Summon lifetimes (beyond the review)

Gnomeregan#4 (Emi's pack summons use a corpse despawn) is one instance of a systemic defect: ScriptDev2 summons nearly everything with `TEMPSPAWN_DEAD_DESPAWN` - the corpse lies, lootable, until it decays - while the port used `SummonCorpseDespawn` / `MarkCorpseDespawn`, which removes the corpse the moment the creature dies. Loot of summoned bosses was lost: the Ring of Law bosses and Theldren's band, Hurley Blackbreath, Watcher Doomgrip, Baron Aquanis, Gandling, Kirtonos, Ramstein, Gyth, Rend, Mizzle, Atal'alarion, Mutanus, Grubbis. `076a6861` adds `CreatureMapSystem.SummonDeadDespawn`, makes `SummonForInstance` do what its summary already said (DEAD_DESPAWN), and moves each call site to the type its reference uses (checked one by one against the SD2 source and, for Kirtonos and the Risen Guardians, the ClassicDB z2815 `dbscripts_on_go_use 2890009` / `dbscripts_on_event 5618-5623` command-10 rows: `TEMPSPAWN_TIMED_OOC_OR_DEAD_DESPAWN`, ScriptMgr.cpp:2062). Kept as corpse despawn, as in the source: Thermaplugg's walking bombs and the player-summoned Nefarius/Rend of the stadium event. Alterac Valley and the raid scripts were not touched.

## Test infrastructure

`DungeonScriptHarness.AddPlayer` entered an ungrouped second player into an instance of its own, not the first player's, despite its summary. It now groups the two and asserts the shared map. Existing tests that used it (Doan) still pass.
