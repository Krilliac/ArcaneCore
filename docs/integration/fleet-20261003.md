## Shared seams and validation

- `Map.cs` retains map updaters while using the grid index. Player removal runs
  updater callbacks before clearing visibility. `AddObject` accepts an
  `isNewObject` flag so transient creature/corpse create packets retain their
  existing wire shape. Player relocation requests a visibility pass; pending
  observer creates are flushed before object destruction to prevent ghost objects.
- Creatures and corpses use the map's object registry and grid lifecycle. Creature
  lookup, retaliation, death, terrain height, eviction, and respawn share combat
  and visibility ownership. Crossing a grid boundary cannot duplicate a spawn on
  home-grid reload. Logout removes a corpse from its actual map after transfer.
- Spell damage uses map combat and suppresses unintended white swings and melee
  rage. Healing threat enters combat. Player spell teleports use the existing
  acknowledgement flow, preserving spell state while detached between maps.
  Character hooks persist starting spells before successful creation and reload
  spellbooks after ordered writes. Failed learn/unlearn writes are reconciled from
  the authoritative cache before relog; failed recovery aborts the load.
- Missing quest objective, timer, and menu implementations now compile and have
  regression coverage. Stale player callbacks cannot credit or untrack a new
  session. Failed inventory insertion does not charge a vendor buyer or consume
  stock. Quest-only NPC details and vendor gossip retain their reference wire
  behavior. M13a/M13b below add bounded daemon registration and adapters;
  broader reward/objective and NPC services remain subsequent work.
- `MovementHandlers.cs` ignores movement and root acknowledgements while a
  teleport is pending; the near-teleport loopback test covers a stale heartbeat.
- Duplicate legacy `WorldV1Context` test fixtures were separated. Spell data
  assertions use assigned module versions.
- `IntegratedSchemaTests` covers every discovered module and mapped feature
  table, fresh shared-database startup, legacy upgrades, and idempotence on the
  existing provider matrix.
- Creature replacement now wraps all deletes and every 2,000-row batch in one
  transaction or a savepoint in the caller's EF transaction. Cancellation does
  not cancel rollback. Late failure/cancellation restores all five tables and
  preserves prior caller work; tracked caller state is refused before writes.
- M13a loads journal fields before self-create and registers logged-in quest
  and NPC text queries. Timers run on every map and retain state across far
  transfers. Failed quest/taxi writes retain authoritative snapshots for login
  and shutdown recovery; monotonic revisions reject stale reconnect loads.
  Self-visible group-only quest IDs and early friend offline notifications
  have regression coverage. M13b below adds ordinary NPC journal interactions.
