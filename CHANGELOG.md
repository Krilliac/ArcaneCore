# Changelog

## Unreleased

- Spells: the first Ignite on a target no longer adds the mage's +fire damage, percent damage auras or damage over time talents on top of its share of the crit, because that share already includes them.
- Economy: a configured `Economy:AuctionHouses` entry for house 2, 6 or 7 now replaces that house's percentages (it used to have no effect), and an entry with a field missing or unreadable now fails the start and `check-config` naming the key (it used to be dropped without a message).
- Creatures: creature spell lists now run. The world database gains the five cmangos list and condition tables (world schema 68) and `creature_template.SpellList`, the importer and store load them, and creatures whose AI runs lists cast from them on the 1200 ms tick. EventAI action 60 and the `creature.set_spell_list` rule action change a list, and the seven Alterac Valley commanders ship with lists in `sql/content`. `Creatures:SpellListContinueAfterCast` (default off, retail) follows the cmangos code loop instead.
- Spells: base spell crit now comes from intellect (the reference class table, not yet proven against retail) instead of a flat 5% for every player. Spell crit rises with intellect above the baseline, drops slightly below it, and falls to near 0 for warriors, rogues and hunters. Non-player units keep 5%. This changes live balance once deployed. With `Stats:RequireImportedData` false (the default) and neither imported player base data nor `Progression:LevelStatsPath` level stats supplying base stats, a mage's base intellect is 0, so spell crit reads about 3.7% (the table base) plus any intellect from gear and auras, instead of the intellect-scaled value.
- Docs: the build charter (`ARCANECORE_CHARTER.md`) and the per-milestone pages (`MILESTONE_*.md`, `docs/M*_ACCEPTANCE.md`) are retired. The binding rules moved to `docs/guide/contributing.md`; protocol decisions, the real-client checklist and the mock client now have their own pages. Git history keeps the old text. The README describes the current project.
- Content importer: the `import`, `import-dbc`, `import-map-dbc`, `proc-events` and `spell-threat` verbs now exit 3 on a world database whose schema is behind, instead of upgrading it silently. Pass `--migrate` (throwaway or staging worlds) or run `arcane-db upgrade` (production worlds). See [database-upgrade.md](docs/ops/database-upgrade.md).
- Logging: the `Logging:ArcaneCore:Json:Path` deprecation warning now fires only when a file sink is enabled; with logging off the key has no effect and no longer fails startup under `Startup:Strict`. A reload that leaves the resolved log file unchanged (for example moving the path between `Logging:ArcaneCore:Json:Path` and `Logging:ArcaneCore:File:Path`) no longer logs a restart-only notice.
- Logging: the text and JSON sinks now escape Unicode format characters (bidi overrides such as U+202E, zero-width U+200B, the byte order mark U+FEFF) as `\uXXXX`, in addition to control characters.
